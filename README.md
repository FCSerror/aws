## Week 3 — Aug 22–28 — Domain 3: Compute, Storage, Networking & Management

- **Sun 8/23** — Networking: VPC, subnets, internet/NAT gateways, Route 53, CloudFront, Direct Connect.
- **Mon 8/24** — Databases: RDS, Aurora, DynamoDB, Redshift — relational vs. NoSQL vs. warehouse, conceptually.
- **Tue 8/25** — Quiz on compute/storage/network/database subset. *(Pocket Prep: Domain 3 quiz #1, untimed)*
- **Wed 8/26** — Recap the week; re-skim any service overview page that still feels unfamiliar.

- **Fri 8/28** — Migration & deployment: CloudFormation, Snow Family, DMS, Organizations; light pass on ML/analytics awareness.
